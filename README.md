# Portafolio Personal - Juan Andrés Muñoz Zapata

Este proyecto es un portafolio personal desarrollado en **HTML y CSS puro**, diseñado para ser simple, limpio y fácil de mantener.

##  Estructura del Proyecto

El proyecto está organizado de la siguiente manera:
- `project_code/`: Carpeta que contiene la lógica y estructura del sitio (archivos `.html` y `.css`).
- `fotos/`: Carpeta destinada a los recursos visuales y fotografías.

##  Cómo Visualizar el Proyecto

Al tratarse de un sitio web estático, no es necesario instalar dependencias ni configurar servidores. Para verlo en funcionamiento:

1. Abre la carpeta `project_code`.
2. Haz doble clic sobre el archivo `index.html`.
3. El sitio se abrirá automáticamente en tu navegador web predeterminado.

##  Compilación

Este proyecto **no requiere compilación**. 

Utiliza tecnologías estándar de la web (HTML5 y CSS3) que son interpretadas directamente por cualquier navegador moderno. No se utilizan frameworks, preprocesadores ni herramientas de construcción (*build tools*).

##  Guía de Modificación

El código está comentado y estructurado para facilitar cambios rápidos:

- **Contenido:** Para cambiar textos, enlaces o agregar secciones, edita los archivos `.html` correspondientes.
- **Estilos:** Para modificar colores (paleta beige), tipografías o espaciados, edita el archivo `styles.css`.
- **Imágenes:** Para actualizar la foto de perfil, reemplaza el archivo en la carpeta `fotos/` asegurándote de que el nombre siga siendo `foto_juan.jpeg`.
